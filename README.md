# destination-archive

Personal archive from the years I spent comparing places I wanted to see in
person. The shortlist stopped at three, the planning never went further, and
the folder has been left as it was.

## Contents

| Path | What it holds |
| --- | --- |
| `docs/candidates.md` | the three places that made the shortlist |
| `docs/notes.txt` | scratch notes kept next to the shortlist |
| `profile/archive.json` | metadata for the archived copy |
| `CHANGELOG.md` | changes made to this folder |

Nothing here is maintained any more.
